# Справочник по разгону: NVIDIA / Intel / AMD

## ⚠️ Важно прочитать перед использованием

Здесь **нет** таблицы вида "для этой модели ставь вот такую частоту и вольтаж".
Причина простая: максимальный стабильный разгон - не характеристика модели,
а характеристика **конкретного экземпляра чипа** (кремниевая лотерея).
Один 9800X3D стабильно держит +200 МГц, другой словит BSOD на +50 МГц.
Готовая таблица "максимума" для модели либо бесполезна (занижена), либо
опасна (завышена для части пользователей - нестабильность, перегрев,
в редких случаях деградация чипа).

**Подход, который используется ниже:** снятие/поднятие заводских лимитов
мощности (Power Limit / PPT / PL1-PL2) до безопасного диапазона,
который производители сами закладывают в тюнинг-утилиты (обычно 105-125%
от штатного значения). Это даёт реальный, воспроизводимый прирост
(обычно 3-10% FPS) без лотереи с вольтажом и без риска сжечь чип.
Дальнейший ручной разгон (curve offset, множители) скрипты применяют
**маленькими safe-шагами с проверкой стабильности**, а не сразу "в максимум".

## 2. Intel Core (13th/14th/15th Gen, K-серия - актуальны для разгона)

Официальные PL1/PL2 (Intel Extreme Tuning Utility работает через эти лимиты).
"Разгон" через XTU CLI в безопасном сценарии = снятие троттлинга (PL1 поднимается
до уровня PL2, убирается тайм-лимит Tau), а не ручной множитель ядра.

| Модель | Base PL1 (заводской) | Max PL2 (заводской) | Safe-таргет PL1=PL2 |
|---|---|---|---|
| Core i9-14900K / 15th Gen аналог (Core Ultra 9 285K) | 125 Вт | 253 Вт | 253 Вт |
| Core i7-14700K / Core Ultra 7 265K | 125 Вт | 253 Вт | 253 Вт |
| Core i5-14600K / Core Ultra 5 245K | 125 Вт | 181 Вт | 181 Вт |
| Core i9-13900K | 125 Вт | 253 Вт | 253 Вт |
| Core i7-13700K | 125 Вт | 253 Вт | 253 Вт |
| Core i5-13600K | 125 Вт | 181 Вт | 181 Вт |

> Ручной разгон множителя ядра (например +1-2 бина/100-200 МГц) технически
> возможен через XTU CLI, но требует индивидуального стресс-теста (Prime95/OCCT)
> под конкретное охлаждение - фиксированных "лучших" чисел для модели не существует.
> Скрипт ниже поэтому делает: (1) снятие лимита мощности до заводского PL2,
> (2) включение Turbo Boost Max 3.0 / Thermal Velocity Boost если доступны,
> без слепого поднятия множителя.

## 3. AMD Ryzen (7000 / 9000 series, включая X3D)

AMD сам рекомендует **PBO (Precision Boost Overdrive) в режиме Auto**, а не ручные
оффсеты - это официально задокументированная позиция AMD, т.к. auto-режим
использует телеметрию конкретного чипа (то же, что делает Ryzen Master).

| Модель | Заводской PPT | Safe PBO PPT (Auto/Advanced лимит) | TDC / EDC (заводские) |
|---|---|---|---|
| Ryzen 9 9950X3D | 170 Вт | 200 Вт | 160А / 225А |
| Ryzen 9 9950X | 170 Вт | 200 Вт | 160А / 225А |
| Ryzen 9 9900X | 120 Вт | 150 Вт | 120А / 170А |
| Ryzen 7 9800X3D | 120 Вт | 162 Вт | 130А / 225А |
| Ryzen 7 9700X | 65 Вт (Eco) / 88 Вт | 105 Вт | 75А / 150А |
| Ryzen 5 9600X | 65 Вт (Eco) / 88 Вт | 105 Вт | 75А / 150А |
| Ryzen 9 7950X3D | 120 Вт | 162 Вт | 130А / 225А |
| Ryzen 9 7900X | 170 Вт | 200 Вт | 160А / 225А |
| Ryzen 7 7800X3D | 120 Вт | 162 Вт | 130А / 225А |
| Ryzen 5 7600X | 105 Вт | 142 Вт | 90А / 170А |

> Для X3D-моделей AMD и производители плат прямо не рекомендуют ручной
> Curve Optimizer offset сильнее -15...-20 (все ядра) без индивидуального теста -
> у 3D V-Cache чипов ниже предел по напряжению. Скрипт использует
> **Curve Optimizer Auto + консервативный PBO limit**, без слепого фиксированного offset.

## Что делают скрипты

- `nvidia_tweak.py` - читает реальные min/default/max power limit с карты через NVML,
  выставляет 108-110% от заводского (никогда не выше `max`, который сама NVIDIA
  разрешает для этой карты).
- `intel_xtu_tweak.py` - обёртка над `XTU.exe`/`xtucli`, снимает Tau-лимит и
  поднимает PL1 до PL2 (устраняет троттлинг после 56 сек буста), не трогает множители.
- `amd_pbo_tweak.py` - обёртка, применяющая PBO Advanced с лимитами из таблицы
  выше через `ryzenadj` (open-source CLI, т.к. официального CLI для Ryzen Master нет).

Все три скрипта **запрашивают подтверждение** и логируют исходные значения,
чтобы можно было откатить изменения.
